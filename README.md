# Oldnewwebserver

لوحة مراقبة بسيطة لخادم Hiawatha، تعرض حالة الجهاز وواجهة الشبكة الفعلية عبر صفحة ويب.

## المكونات

| الملف | الوظيفة |
| --- | --- |
| `index.html` | واجهة لوحة المراقبة فقط |
| `styles.css` | تنسيق الواجهة والاستجابة للشاشات الصغيرة |
| `script.js` | طلب القياسات من الخادم وتحديثها كل ثانية |
| `monitor_server.py` | خادم Python محلي وواجهة `/api/metrics` |
| `hiawatha-12.4/` | مصدر خادم Hiawatha المستخرج |

## طريقة التشغيل

من مجلد المشروع:

```bash
python3 monitor_server.py
```

ثم افتح:

```text
http://localhost:8000
```

للسماح بالوصول من جهاز آخر داخل الشبكة فقط، شغّله بعنوان واضح بدل الإعداد المحلي الافتراضي:

```bash
MONITOR_HOST=0.0.0.0 MONITOR_PORT=8000 python3 monitor_server.py
```

## القياسات

يقرأ `monitor_server.py` البيانات مباشرة من Linux:

- **RAM:** من `/proc/meminfo`
- **CPU:** من فرق عدادات `/proc/stat`
- **Hard Disk:** من مساحة القرص `/`
- **Internet Speed:** من عدادات الإرسال والاستقبال في `/proc/net/dev`
- **Response Time:** زمن معالجة طلب `/api/metrics` بالنانوثانية
- **Architecture:** نوع Python والآلة مثل `64bit / x86_64`
- **Operating System:** اسم وإصدار نظام التشغيل
- **File Check:** فحص دائم لتغيّر ملفات المشروع وإظهار عدد الملفات المفحوصة

يختار الخادم أول واجهة شبكة فيزيائية متاحة، مثل `eth0`. سرعة الإنترنت هي معدل النقل الفعلي لحظة القياس، وليست سرعة الاشتراك النظرية.
فحص الملفات يعتمد على metadata ولا يقرأ محتوى الملفات أو يحسب hash في كل دورة، حتى يبقى خفيفًا.

لتغيير الفاصل بين الفحوصات:

```bash
FILE_SCAN_INTERVAL_MS=100 MONITOR_PORT=8000 python3 monitor_server.py
```

أقل قيمة مسموحة هي `10ms`. وقت الفحص نفسه يسجل بدقة النانوثانية، لكن تشغيل الفحص كل نانوثانية غير ممكن عمليًا.

## الاختبار

```bash
python3 -m py_compile monitor_server.py
node --check script.js
curl http://localhost:8000/api/metrics
```

تم اختبار بناء Hiawatha native على Linux `x86_64`. اختبار 32-bit يحتاج تثبيت مكتبات وأدوات `multilib` المناسبة للنظام.

## ملاحظات أمنية

الخادم مخصص للتطوير والمراقبة المحلية، ويستمع افتراضيًا على `127.0.0.1:8000`. لا تعرضه مباشرة للإنترنت دون إضافة مصادقة وHTTPS وتقييد قواعد الجدار الناري.
